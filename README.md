# Online
Online Retail Data Analysis with SQL

## 📌 專案簡介 (Project Overview)
本專案為端到端 (End-to-End) 零售數據分析專案，涵蓋資料清洗 (ETL)、SQL 數據挖掘與 Power BI 高階視覺化儀表板建立。

## 🛠️ 技術流程與工具 (Pipeline & Tech Stack)
1. **Data Cleaning & Preprocessing (Python / Pandas)**
   - 使用 Google Colab 處理缺失值 (Missing Values)、異常值 (Outliers) 及資料型態轉換。
   - [![Open In Colab]https://colab.research.google.com/drive/1OK977olh0ZQBR6XmLSNF4Zmr0vvn3ITT
2. **Data Query & Analytics (SQL / MySQL)**
   - 撰寫語法計算 RFM 顧客分群與購物籃交叉銷售分析 (Market Basket Analysis)。
3. **Interactive Visualization (Microsoft Power BI)**
   - 建立 Executive Overview 與 Customer Analytics 兩頁高階商業儀表板。
